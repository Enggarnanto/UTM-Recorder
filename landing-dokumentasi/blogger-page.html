Yang bisa dilakukan

Satu tempat untuk membaca perjalanan pengunjung.

UTM Traffic Recorder menghubungkan kunjungan, atribusi kampanye, dan klik WhatsApp dalam dashboard WordPress.

Dashboard trafik

Lihat ID browser unik, sesi unik, pageviews, kunjungan ber-UTM, dan klik WhatsApp pada periode yang dipilih.

UTM Manager

Urai source, medium, campaign, content, term, dan match type. Filter kunjungan, lihat sesi, dan ekspor CSV.

Dashboard Chat WA

Periksa jumlah klik, sesi yang mengklik, akun teratas, ID sesi, dan sumber tiap klik yang tercatat.

CTA multiadmin

Satu tombol mengambang membuka daftar admin. Atur avatar, jadwal, halaman, urutan, warna, ukuran, dan shortcode.

Pesan bersumber

Tambahkan baris sumber dari UTM dan ID terpilih. Saat tak ada UTM, gunakan URL halaman atau link khusus.

Kontrol sesuai kebutuhan

Pilih UTM laporan, aktifkan pelacakan tautan WA lama, dan sembunyikan UTM dari address bar melalui Clean URL.

Cara kerja

Dari tautan kampanye hingga laporan.

Plugin berjalan di halaman publik, lalu mengirim peristiwa kunjungan dan klik yang valid ke WordPress.

01

Pengunjung tiba

Halaman dibuka dengan atau tanpa UTM. Parameter pada tautan baru dibaca saat halaman dimuat.

02

Identitas lokal

ID browser disimpan untuk domain itu; setiap tab memiliki ID sesi sendiri. UTM aktif diperbarui saat ada tautan UTM baru.

03

Peristiwa tercatat

Pageview dan klik WA yang valid dikirim ke database WordPress bersama ID serta kolom UTM laporan yang aktif.

04

Laporan dibaca

Dashboard menampilkan agregat, detail peristiwa, sesi terkait, dan ekspor data menurut filter.

UTM baru?Seluruh set UTM aktif diganti. Misalnya GADS + CPC lalu membuka tautan hanya dengan utm_source=EMAIL, medium berikutnya menjadi kosong.

Mulai cepat

Setup dalam lima langkah.

Siapkan plugin, buat akun WhatsApp, dan uji dengan kunjungan sungguhan dari jendela privat.

01

Instal & aktifkan

Di WordPress, buka Plugins → Add New → Upload Plugin. Pilih paket plugin yang sudah Anda miliki, lalu aktifkan. Panduan resmi WordPress ↗

02

Pilih UTM laporan

Buka Traffic Recorder → Settings. Centang parameter yang ingin dicatat pada laporan baru. Simpan pengaturan.

03

Buat akun CTA WA

Isi nama admin, nomor internasional tanpa tanda +, pesan, avatar, hari aktif, dan halaman. Simpan akun.

04

Uji sebagai pengunjung

Buka URL contoh di jendela privat atau saat tidak login. Klik CTA WA, lalu periksa teks sumber sebelum mengirim pesan.

05

Periksa dashboard

Lihat pageview dan sesi di Dashboard Trafik & UTM, detail di UTM Manager, serta klik di Dashboard Chat WA.

Contoh untuk pengujian

Ganti domain contoh dengan domain WordPress Anda. Contoh ini tidak mengirim data apa pun dari halaman dokumentasi.

URL dengan UTM
https://example.com/kelas/?utm_source=GADS&utm_medium=CPC&utm_campaign=PROMO_A&utm_content=GRUP_A&utm_term=KURSUS
Shortcode akun WA
[utr_whatsapp id="1"]

Butuh WordPress 6.0+, PHP 7.4+, JavaScript, dan WordPress REST API pada halaman publik. Kunjungan pengguna yang login tidak masuk laporan.

Pesan WhatsApp

Pesan rapi, sumber tetap terbaca.

Tulis pesan akun dalam beberapa baris. Plugin menambah baris sumber setelah satu baris kosong saat tombol atau tautan WA yang didukung diklik.

Dengan UTM

Pilih source, medium, campaign, content, term, match type, ID sesi, atau ID browser. Atur label, huruf, dan pemisahnya.

Tanpa UTM

Aktifkan atau matikan fallback. Ubah label dan pilih URL halaman pengunjung atau link khusus.

Beberapa admin

Satu launcher membuka daftar akun. Prioritas, hari aktif, halaman, dan visibilitas daftar chat bisa diatur.

Tautan lama

api.whatsapp.com/send, wa.me/send, dan wa.me/nomor didukung. Penambahan sumber dan pencatatan klik punya toggle terpisah.

Contoh pesan yang dibuka
Halo Kak,
saya ingin bertanya tentang program ini.

Sumber: GADS+a1b2c3d4

Ilustrasi format bawaan. Isi pesan, label, dan nilai sebenarnya mengikuti pengaturan situs Anda.

Pilihan sumber pesan

Mode localStorage memakai UTM aktif terbaru, termasuk kunjungan berikutnya pada browser yang sama. Mode sesi memakai UTM yang diterima tab saat itu; tab baru tanpa UTM dapat memakai fallback URL.

Enam parameter laporan

Settings mengatur UTM yang tercatat pada kolom laporan WordPress. Pilihan pada CTA WA hanya mengatur baris sumber pesan. Keduanya terpisah dan tidak mengubah data lama.

Beranda tidak menampilkan tombol?

Jika akun diatur untuk “Hanya halaman yang dipilih”, centang juga “Beranda / homepage”. Periksa hari aktif, toggle floating, toggle daftar chat akun, serta cache halaman.

Klik ≠ pesan terkirim

Dashboard Chat WA mencatat klik yang berhasil diproses. Plugin tidak mengetahui apakah pesan WhatsApp kemudian dikirim, diterima, atau dibaca.

Sesi unik ≠ orang unik

Satu browser dapat membuka beberapa tab atau sesi. Browser atau perangkat lain, mode privat, dan penghapusan data situs dapat menghasilkan ID baru.

Perujuk bergantung pada browser

URL perujuk lengkap tampil hanya jika browser dan situs asal memberikannya. Nilainya bisa berupa domain saja atau kosong.

Clean URL bekerja di browser

UTM dihapus dari address bar setelah skrip berjalan. URL awal tetap masuk pada permintaan halaman pertama dan bisa terlihat sebentar.

Yang tidak disimpan

Plugin tidak menyimpan alamat IP, user agent, atau teks utama pesan WhatsApp dalam catatan klik. Baris sumber tambahan tetap tersimpan.

Batas teknis pencatatan

JavaScript, REST API, serta penyimpanan browser perlu bekerja. Pemblokir privasi atau cache skrip lama dapat membuat pencatatan gagal atau ID berubah.

Mengubah pilihan UTM hanya berlaku untuk data baru; riwayat lama tidak ditulis ulang. Ekspor CSV mengikuti filter dan memakai waktu UTC, sedangkan dashboard menampilkan zona waktu WordPress. Penghapusan plugin melalui WordPress menghapus tabel laporan dan opsi plugin.

Pertanyaan umum

Jawaban untuk kasus yang paling sering muncul.

Mengapa tombol floating tidak muncul di homepage?

Periksa apakah tombol mengambang aktif, ada akun yang aktif pada hari tersebut, dan toggle “Daftar chat” akun menyala. Jika ketersediaan memakai “Hanya halaman yang dipilih”, centang “Beranda / homepage”. Setelah menyimpan, bersihkan cache halaman atau CDN.

Mengapa UTM masih terlihat di address bar?

Pastikan Clean URL aktif di Settings atau UTM Manager. Hapus cache halaman/CDN agar skrip terbaru dimuat. Clean URL memerlukan JavaScript dan berjalan setelah halaman mulai dimuat; UTM awal tetap dapat terlihat singkat serta tetap terkirim pada permintaan pertama.

Mengapa URL perujuk hanya menampilkan domain?

Browser atau situs asal dapat membatasi informasi perujuk melalui kebijakan referrer. Plugin menampilkan URL lengkap hanya saat browser mengirimkannya. Data lama yang dahulu hanya menyimpan domain tidak dapat direkonstruksi menjadi URL lengkap.

Mengapa ID browser atau ID sesi bisa kosong?

Catatan lama dapat berasal dari versi sebelum kedua ID diwajibkan. Sejak versi 2.4.2, pencatatan baru hanya menerima ID browser dan ID sesi yang sama-sama berupa UUID valid. Jika data baru tidak muncul, periksa cache skrip, JavaScript, REST API, dan pemblokiran penyimpanan browser.

Apakah pilihan UTM di Settings dan CTA WA saling membatasi?

Tidak. Settings menentukan kolom UTM untuk laporan baru di WordPress. Pilihan dalam CTA WA menentukan nilai yang muncul pada baris sumber pesan. Nilai yang dipilih untuk pesan bisa ada walau kolom laporan terkait kosong.

Apakah UTM lama tetap dipakai saat kampanye baru hanya mengirim source?

Tidak. Tautan yang membawa UTM baru mengganti seluruh set UTM aktif. Jika hanya source yang ada, medium, campaign, content, term, dan match type sebelumnya menjadi kosong.

Apakah klik WhatsApp dihitung sebagai chat yang berhasil?

Tidak. Plugin mengetahui klik tautan yang diproses, bukan status pengiriman atau balasan di aplikasi WhatsApp.

Bagaimana data dihapus?

Riwayat lebih dari 90 hari dibersihkan otomatis melalui WP-Cron saat WordPress menerima kunjungan. Menghapus plugin dari WordPress menjalankan uninstall yang menghapus tabel laporan dan opsi plugin. Jika riwayat masih dibutuhkan, cadangkan database sebelum menghapus.
